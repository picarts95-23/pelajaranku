# Adventure Academy

Saya akan membuat aplikasi untuk media pembelajaran yang interaktif serta fungsional berbasis RPG. Aplikasi ini akan menampilkan Dashboard bagi guru dan siswa dengan beberapa fitur. 



Saya terinspirasi dari app dualingo, Quiziz,  serta aplikasi belajar seru lainnya yang tidak hanya berfungsi sebagai media ajar, tetapi juga sebagai penyedia keperluan administrasi bagi guru. Aplikasi ini akan memiliki design yang dapat menarik perhatian siswa bertemakan RPG dan tampak professional dengan visualisasi data yang informatif.  



Fitur yang akan saya implementasikan untuk pertama : 



  a.   Halaman utama dengan tampilan yang menarik bagi siswa dilengkapi menu pendaftaran / login terpisah untuk role guru dan siswa. 



  b.   Setelah berhasil mendaftar dan login, maka halaman agar loading menuju dashboard sesuai role guru dan siswa.



  c.   Buat sistem auntentifikasi dengan 2 role yaitu guru dan siswa dan buatkan akun dammynya.
