Halaman ini bisa dibuka tanpa internet setelah dimuat sekali. Simpan / bookmark untuk akses cepat.

💾 Unduh ke Perangkat ↩︎ Buka Panduan Interaktif

Status koneksi: memeriksa…

Cara menyimpan supaya bisa dibaca offline:
  • Android/Chrome: ketuk ⋮ → Unduh halaman atau Tambahkan ke Layar Utama.
  • iPhone/Safari: ketuk ikon Share ⬆️ → Add to Home Screen atau Options → Save PDF to Files.
  • Laptop: tekan Ctrl/⌘ + S untuk simpan, atau klik Unduh ke Perangkat.

✅ Sebelum Kirim, Periksa

  • Tenggat waktu — kalau lewat, tombol Kirim otomatis mati.
  • Koneksi — pastikan Wi-Fi / sinyal stabil saat menekan Kirim.
  • Ukuran file maksimal 15 MB (foto & audio).
  • Browser Chrome / Safari / Edge / Samsung Internet versi terbaru.
  • Baca pesan error di layar — biasanya menjelaskan penyebabnya.

📝 Cara Mengirim Tugas (per jenis)

📷 Tugas Foto / Gambar

  1. Buka menu Tugas, pilih tugas bertipe foto.
  2. Ketuk Ambil Foto (kamera) atau Pilih dari Galeri.
  3. Pastikan gambar terang, jelas, dan ≤ 15 MB.
  4. Tekan Kirim. Tunggu notifikasi berhasil.

🎙️ Tugas Rekaman Suara

  1. Buka tugas, ketuk Rekam.
  2. Izinkan mikrofon saat browser bertanya.
  3. Rekam dekat mikrofon, ketuk Stop, lalu Putar untuk memeriksa.
  4. Tekan Kirim.

iPhone/Safari: pakai versi Safari terbaru agar rekaman berjalan.

🔗 Tugas Link (Form / Kuis)

  1. Buka tugas, ketuk tombol link dari guru.
  2. Kerjakan di tab yang terbuka.
  3. Kembali ke Pelajaranku, tandai selesai bila diminta.

🧠 Kuis Pilihan Ganda

  1. Buka tugas bertipe Kuis.
  2. Jawab tiap soal — kamu hanya bisa kirim satu kali.
  3. Setelah semua terjawab, tekan Kirim Jawaban.
  4. Nilai otomatis muncul langsung.

✍️ Tugas Uraian

  1. Tulis jawaban di kolom teks.
  2. Opsional: lampirkan foto atau tempel URL (https://...).
  3. Periksa ejaan, tekan Kirim.

📖 Muroja'ah Tahfidz

  1. Perhatikan surat/ayat yang harus disetor.
  2. Ketuk Rekam, baca dengan tartil.
  3. Ketuk Stop, Putar untuk cek, lalu Kirim.

🛠️ Gagal Upload? Coba Ini

Izin Kamera / Mikrofon

  • Android/Chrome: ketuk 🔒 di address bar → Izin situs → aktifkan Kamera & Mikrofon → muat ulang.
  • iPhone/Safari: Pengaturan iOS → Safari → Kamera / Mikrofon → Izinkan.
  • Laptop: klik 🔒 di address bar → Site settings → izinkan Camera & Microphone → reload. Tutup Zoom/Meet bila berjalan.
  • Kalau kamera dipakai aplikasi lain (Zoom/WA), tutup dulu.

Ukuran File Terlalu Besar (>15 MB)

  • Buka Galeri → Edit → Simpan salinan lebih kecil.
  • Atau screenshot foto lalu kirim screenshot-nya.
  • Laptop: gunakan Paint / Preview untuk resize ke ≤ 1600 px.
  • Rekaman panjang → pecah jadi 2 rekaman pendek.

Format File Tidak Didukung

  • Foto: JPG / JPEG / PNG / WEBP / HEIC.
  • HEIC gagal? Pengaturan iOS → Kamera → Format → Paling Kompatibel.
  • Audio (dari tombol Rekam): m4a / mp3 / webm / ogg / wav.
  • Link: harus lengkap, diawali https://.
  • File tanpa ekstensi (mis. dari WhatsApp): ganti nama, tambahkan .jpg / .mp3.

Upload Macet / Gagal Terkirim

  • Sinyal lemah — dekati Wi-Fi atau pindah tempat.
  • Jangan tutup tab sampai muncul notifikasi Berhasil.
  • Laptop: nonaktifkan VPN / ekstensi pemblokir upload.
  • Kalau macet lama: muat ulang halaman, lalu kirim ulang (rekaman/foto perlu dipilih ulang).

⚠️ Pesan Error yang Sering Muncul

  • "Tenggat tugas sudah lewat" — tidak bisa lagi dikirim. Hubungi guru lewat menu Minta Tugas.
  • "Rekaman kosong" — mikrofon tidak menangkap suara. Cek izin & rekam ulang dekat mikrofon.
  • "Upload rekaman/foto gagal" — koneksi terputus. Muat ulang & kirim ulang.
  • "Foto kosong / Ukuran maks 15 MB" — pilih ulang atau kompres foto.
